# Automated-MangaDex-Chapter-Downloader-via-Official-API
Herramienta hecha en Python (Jupyter) para los traductores de historietas japonesas (Mangas). Permite descargar los pngs asociados a un capítulo elegido a través de la API oficial de Mangadex.

Guía de uso:

-El código está listo para su uso y solo requiere que se modifique el ID del capítulo elegido en la sección de "Configuración" de la celda 2:

<img width="987" height="127" alt="image" src="https://github.com/user-attachments/assets/c108aa98-9167-4bf2-a016-0321ae3bf67e" />

-¿Dónde encontrar el ID del capítulo a descargar?

Un episodio almacenado en la página de Mangadex tiene la siguiente estructura:

https://mangadex.org/chapter/244fb4b1-c918-4f37-9840-28d156b6ad2f/1

En este caso "244fb4b1-c918-4f37-9840-28d156b6ad2f" indica el ID capítulo, bastará con copiar dicho texto y reemplazarlo en el código para exportar a vuestro pc las imágenes deseadas.
